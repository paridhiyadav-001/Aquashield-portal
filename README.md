# 🌊 AquaShield AI

AquaShield AI is a smart water management and complaint tracking dashboard designed to monitor water issues, officer dispatches, and real-time status updates.

## 🚀 Features
- **Real-Time Analytics:** Live stat counters for total, critical, dispatched, and resolved complaints.
- **Officer & Citizen Portals:** Dedicated flows for logging complaints and managing updates.
- **Fully Responsive UI:** Optimized for Mobile, Tablet, and Desktop screens.
- **Dark/Light Mode:** Dynamic theme toggle support.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Custom CSS Grid & Flexbox

## 📱 Mobile Support
Optimized for seamless operation across all viewport sizes.
