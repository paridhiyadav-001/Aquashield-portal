# 🌊 AquaShield AI - Water Management & Complaint Tracking System

AquaShield AI is an intelligent, real-time web platform designed to monitor water distribution issues, manage citizen complaints, and track officer dispatches.

---

## 🚀 Key Features

- **📊 Live Analytics Dashboard:** Dynamic counters for Total, Critical, Dispatched, and Resolved water complaints.
- **📱 Fully Responsive UI:** Custom CSS Grid & Flexbox setup optimized for Mobile (2x2 layout), Tablet, and Desktop.
- **🏛️ Dual Workflows:** Citizen complaint registration and dedicated Officer status management.
- **🌙 Dark & Light Theme Toggle:** Built-in dynamic theme switcher with CSS root variables.
- **🔍 Specialization & Area Breakdowns:** Interactive modal lookups for regional water tracking.

---

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** CSS3 (Custom Variables, Flexbox, CSS Grid, Media Queries)
- **Logic:** JavaScript (Vanilla ES6+, DOM Manipulation)
